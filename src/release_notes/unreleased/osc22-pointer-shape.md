feature: In terminals that support OSC 22 (answering the launch query), the mouse pointer is an I-beam over the editor text, terminal panes, the Remote view and the text inputs (the popups' value rows and the Search fields), a double arrow over the seams that resize the sidebar, the terminal panel and editor splits, and an arrow everywhere else. "pointer_shape_names" picks the names the shapes are asked for by: "x11" (default, `xterm`, `left_ptr`, ...) or "css" (kitty's `text`, `default`, `ew-resize`, ...).
