fix: Every interactive icon (header icons in Explorer, Search, Source Control and Remote, the open-tabs button, the layout toggles) highlights under the pointer in the active theme's own accent, no longer a navy chip or a fixed blue, and the SEARCH header's refresh and clear icons are bold like the other view headers.
