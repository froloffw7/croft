feat(editor): `column_select_mode` in `config.json` chooses the chords for Column Select, Expand / Shrink Selection and Copy Line. `"vscode"` (the default) is the VS Code scheme: Ctrl/Cmd+Shift+Alt+arrows select a column; Shift+Alt+Right/Left expand and shrink and Shift+Alt+Up/Down copy the line. `"shift_alt"` is Visual Studio's: Shift+Alt+arrows and PageUp/PageDown select a column, Expand / Shrink move to Ctrl/Cmd+Shift+Alt+Right/Left and Copy Line to Ctrl/Cmd+Shift+Up/Down.
